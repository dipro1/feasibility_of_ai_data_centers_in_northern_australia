# Data and licences

The code in this repository is MIT-licensed (see `LICENSE`). The input data
come from third parties and keep their own terms. Files that the scripts can
download again are regenerated by `run_all` and are listed so they can be
removed if a data owner asks.

| Data (path) | Source | Terms |
|---|---|---|
| `inputs/weather/` | NASA POWER (Langley Research Center) | Free to use; acknowledge NASA POWER |
| `inputs/prices/` | AEMO Price and Demand data | AEMO copyright permission: use with attribution to AEMO |
| `inputs/grid/` | AEMO Dispatch SCADA and CDEII, aggregated | AEMO copyright permission: use with attribution to AEMO |
| `inputs/cq_network/osm_*` | OpenStreetMap contributors (Overpass API) | Open Database Licence (ODbL) 1.0; (c) OpenStreetMap contributors |
| `inputs/cq_network/buses.csv`, grid-section curves in `inputs/study_config.json` | Powerlink Queensland, Transmission Annual Planning Report 2025 (values transcribed or digitised) | Cited public report; values only, no report content reproduced |
| `inputs/site_cases.csv`, `inputs/pilbara_ring_lines.csv` | Powerlink TAPR 2025; Horizon Power network capacity information | Cited public reports; values only |
| Cost, emission and inertia values in `inputs/study_config.json` | CSIRO GenCost 2025-26, DCCEEW NGA Factors 2025, AEMO 2024 Inertia Report, Powerlink network tariffs | Cited public reports; values only |
| `inputs/traces/` (not in the repository) | Alibaba cluster-trace-gpu-v2020 | No licence stated; downloaded by `build_gpu_trace_profile.py`. Cite Weng et al., NSDI 2022 |

All other files (`inputs/candidate_sites.csv`, the remaining configuration and
every script) are the author's own work.
